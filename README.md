# 🎬 Netflix Movies & TV Shows Data Analysis

## 📌 Project Overview
This project explores the Netflix Movies and TV Shows dataset to uncover trends in content type, genre distribution, release patterns, and country-wise contributions. The dataset was cleaned and analyzed using Python and SQL, and key findings were visualized through an interactive Power BI dashboard.

## 🎯 Objectives
- Clean and preprocess raw Netflix data to handle missing values, duplicates, and inconsistent formatting.
- Perform Exploratory Data Analysis (EDA) to identify patterns in content type (Movies vs TV Shows), release year, genre, and country of production.
- Use SQL queries to extract deeper insights such as top genres, content additions over time, and rating distributions.
- Design an interactive Power BI dashboard for visual storytelling and easy exploration of trends.

## 🛠️ Tech Stack
| Category | Tools/Technologies |

## 🔍 Key Steps
1. **Data Cleaning** – Handled null values, removed duplicates, standardized date and country fields.
2. **Exploratory Data Analysis (EDA)** – Analyzed distribution of content type, top genres, release trends by year, and country-wise content volume using Pandas and Matplotlib.
3. **SQL Analysis** – Queried the dataset to answer business questions like "Which genres dominate Netflix's catalog?" and "How has content addition changed year over year?"
4. **Dashboard Design** – Built an interactive Power BI dashboard with filters/slicers for content type, genre, country, and release year to enable dynamic exploration of insights.

## 📊 Key Insights
- Identified the split between Movies and TV Shows on the platform and how it has shifted over recent years.
- Highlighted the top contributing countries and most common genres in Netflix's catalog.
- Revealed trends in content additions over time, showing peak years of growth.

## 🚀 How to Run
1. Clone this repository.
2. Install dependencies: `pip install pandas numpy matplotlib`
3. Open `notebooks/netflix_eda.ipynb` in Jupyter Notebook to view the cleaning and EDA steps.
4. Run the queries in `sql/netflix_queries.sql` against the dataset in your SQL environment.
5. Open `dashboard/netflix_dashboard.pbix` in Power BI Desktop to explore the interactive dashboard.
